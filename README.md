# Web-Platform-for-Children-with-Special-Educational-Needs
A responsive educational web platform designed to support children with Special Educational Needs (SEN), their parents, and educators.
About the Project
This platform was developed as part of a research project published in the academic journal Mathematics, Computer Science and Education (MCSE), vol. 8, issue 2, 2025.
The platform provides accessible, adapted educational resources to support the development and learning of every child.
Features:
Educational Games — Interactive math, reading, and social-emotional games adapted for children with SEN
Blog — Articles and tips for parents and educators
For Parents — Resources and guidance for supporting children at home
Contact Page — Easy way to get in touch
Accessibility — OpenDyslexic font toggle for users with dyslexia
Responsive Design — Works on mobile, tablet and desktop
Built With:
HTML5
CSS3
JavaScript (Vanilla)
Font Awesome Icons
Google Fonts (Open Sans)
OpenDyslexic Font
